# web1capstone-website

This project is an improved version of my personal website with CSS styling and Bootstrap integration.

## Project Overview

A personal website shows my education, schedule, gallery, and contact information. Built with HTML, CSS, and Bootstrap.

## Requirements Implemented

### CSS Styling
- Unified external stylesheet (style.css) across all pages
- Consistent background color and Poppins Google Font
- Body set to 90% browser width and centered
- Styled horizontal rules (dashed, shorter, centered)
- Circular profile picture with hover growth effect
- CSS table styling on Education page
- CSS list and form styling
- Pseudo-classes (:hover) and pseudo-elements (::before)

### CSS Layouts (Option B)
- **Float + Position**: Home page (profile image)
- **Flexbox**: Education page (centered table)
- **Grid**: Gallery page (responsive image grid)

### Navigation & Responsive Design
- Sticky navigation bar with hover effects and active states
- Responsive photo gallery (3 columns desktop, 1 column mobile)

### Bootstrap Integration
- Contact page redesigned using Bootstrap
- Bootstrap grid system, card components, form styling
- Utility classes for spacing and shadows

Bootstrap was used to enhance the contact page with pre-built components.

### Bootstrap Experience
- **Easier**: Rapid layout development with grid system, pre-styled components
- **Restrictive**: Customization required CSS overrides, learning curve for class names

## Pages
- Home (Float layout)
- Education (Flexbox layout) 
- Gallery (Grid layout)
- Contact (Bootstrap)
- Weekly Schedule
- Questionnaire
